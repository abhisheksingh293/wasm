# WashMate - Professional Laundry Service

A modern, responsive website for a professional laundry service built with React and Material-UI.

## Features

- Modern, responsive design with beautiful animations
- Dark mode with gradient accents
- Mobile-friendly navigation
- Service booking system
- Contact form
- WhatsApp integration
- College-specific services

## Tech Stack

- React
- Material-UI
- Framer Motion
- Tailwind CSS
- React Router

## Pages

- Home: Landing page with service highlights and testimonials
- About: Company information and team
- Services: Detailed service offerings
- Contact: Contact form and information

## Getting Started

1. Clone the repository
```bash
git clone [your-repo-url]
cd wasmate
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Build for production
```bash
npm run build
```
